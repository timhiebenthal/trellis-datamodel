# dbt Integration

Video tutorials demonstrating dbt integration features.

## Mock Data & Connect dbt Project

If you don't have a dbt project available, but want to play around with trellis you can generate a mock-project.  
Link your dbt project to trellis by providing paths to your dbt project and manifest files in the settings.  
This enables bi-directional sync between your data model and dbt.
